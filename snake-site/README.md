# ثعبان نيون

لعبة ثعبان تعمل كلياً في المتصفح — ملف HTML واحد، بدون أي اعتماديات.

## التشغيل محلياً
افتح `index.html` بالمتصفح مباشرة.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع محتويات هذا المجلد إلى فرع `main`.
2. في المستودع: Settings → Pages → Source = **GitHub Actions**.
3. أول دفعة (push) تنشر الموقع على `https://<username>.github.io/<repo>/`.

## التحكم
الأسهم أو W A S D · مسافة = إيقاف مؤقت · R = إعادة · سحب بالإصبع على الموبايل.
