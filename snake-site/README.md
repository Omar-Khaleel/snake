# ثعبان نيون

لعبة ثعبان تعمل في المتصفح، وتُثبَّت على الهاتف كتطبيق وتشتغل بدون إنترنت.

## النشر
الملفات كلها في جذر المستودع. من GitHub:
**Settings → Pages → Source = Deploy from a branch → Branch: `main` / `(root)` → Save**

الرابط بعدها: `https://<username>.github.io/snake/`

## التثبيت على الهاتف
- **أندرويد (Chrome):** افتح الرابط → قائمة ⋮ → "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية"
- **آيفون (Safari):** افتح الرابط → زر المشاركة → "إضافة إلى الشاشة الرئيسية"

## التحكم
الأسهم أو W A S D · مسافة = إيقاف مؤقت · R = إعادة · سحب بالإصبع أو أزرار الاتجاه على الهاتف.
